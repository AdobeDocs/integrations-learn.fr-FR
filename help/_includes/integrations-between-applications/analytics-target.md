# Intégration [!DNL Analytics] et [!DNL Target]

{{analytics-description}}

{{target-description}}

Les principaux avantages de l’intégration d’Adobe [!DNL Analytics] et d’Adobe [!DNL Target] (A4T) sont les suivants :

+ **Personnalisation pilotée par les données** : utilisez [!DNL Analytics] pour les activités ciblées dans Adobe [!DNL Target], en améliorant les stratégies de personnalisation.
+ **Rapports unifiés** : l’intégration d’A4T combine des rapports [!DNL Target] et [!DNL Analytics] pour une analyse complète.
+ **Ciblage optimisé** : basez les décisions sur des données [!DNL Analytics] pour une segmentation précise de l’audience et une optimisation du contenu.
+ **Audiences partagées** : utilisez [!DNL Analytics] pour créer des segments détaillés et les partager avec les [!DNL Target] afin de les utiliser comme audiences pour les tests.
