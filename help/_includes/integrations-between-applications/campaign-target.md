# Intégration [!DNL Campaign] et [!DNL Target]

{{campaign-description}}

{{target-description}}

Utilisez Adobe [!DNL Campaign] avec Adobe [!DNL Target] pour personnaliser et optimiser le contenu de votre e-mail. Il offre les principaux avantages suivants :

+ **Adobe [!DNL Campaign] data** : améliorez le ciblage dans Adobe [!DNL Target] avec Adobe [!DNL Campaign] data mart.
+ **Segmentation d’audience** : liez les segments à l’identifiant visiteur pour un ciblage optimisé et des expériences personnalisées.
+ **[!DNL Target]Améliorations apportées** : accédez à des données importantes (agent utilisateur, adresse IP, géolocalisation) pour améliorer le ciblage et les campagnes.
