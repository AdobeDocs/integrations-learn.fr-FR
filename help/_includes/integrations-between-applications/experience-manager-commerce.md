# [!DNL Commerce] Experience Manager et Adobe

{{experience-manager-description}}

{{commerce-description}}

L’intégration d’AEM et d’Adobe [!DNL Commerce] à l’aide d’[!DNL Commerce] Integration Framework (CIF) offre plusieurs avantages, notamment :

+ **Accélérez l’innovation** avec des composants commerciaux prêts à l’emploi, ce qui réduit les exigences en matière de code personnalisé.
+ **Favoriser la conversion** par le biais d’expériences personnalisées à l’aide de la couche de données côté client Adobe.
+ **Créez rapidement des expériences commerciales riches et évolutives** avec les outils CIF d’AEM.
+ **Rationalisez la création** et gérez efficacement le contenu des produits sur plusieurs points de contact omnicanaux.
